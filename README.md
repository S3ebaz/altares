# Lente de Altares

Sitio educativo para **leer altares y ofrendas** (Día de Muertos, prehispánico y católico).

La lente coloca etiquetas junto a cada objeto —como una lupa— y explica para qué sirve.

## Cómo usarlo en local

1. Descarga o clona el repositorio.
2. Abre `index.html` en el navegador (mejor Chrome o Safari).
3. En **Lente** elige un ejemplo, sube una foto o permite la cámara.

Las fotos de ejemplo (`ej-*.jpg`) deben estar en la misma carpeta que `index.html`.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo (por ejemplo `lente-de-altares`).
2. Sube todos los archivos de esta carpeta a la rama `main`.
3. En el repositorio: **Settings → Pages**.
4. Source: **Deploy from a branch**.
5. Branch: `main` / folder `/ (root)`.
6. Espera uno o dos minutos. La URL será:

   `https://TU-USUARIO.github.io/lente-de-altares/`

Si Pages no abre `index.html` solo, la dirección completa es:

   `https://TU-USUARIO.github.io/lente-de-altares/index.html`

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | App completa (inicio, lente y fichas) |
| `manifest.webmanifest` | Datos para instalarla como sitio |
| `ej-ofrenda-tres.jpg` | Ejemplo: ofrenda de tres niveles |
| `ej-ofrenda-uno.jpg` | Ejemplo: ofrenda de un nivel |
| `ej-catolico.jpg` | Ejemplo: altar católico de casa |
| `ej-prehispanico.jpg` | Ejemplo: ofrenda prehispánica |

## Nota

En los **ejemplos** las etiquetas están colocadas sobre cada objeto.

Con la **cámara o una foto propia** la app muestra etiquetas de guía. No incluye un modelo de inteligencia artificial entrenado para reconocer cada pieza con precisión.

Contenido educativo y respetuoso con las tradiciones.
